# 考点写法与区分度

考点用于测量题目是否考到了实际判断。先确定业务要求和可核验结果，再写通过条件；不能靠苛刻措辞、隐藏规则或改变分母制造难度。本文件及例子均为作者参考，不随 prompt 或输入附件交给作答模型。

## 数量建议

新建或已授权重构时，**整题推荐40–80个可独立判定的考点**；多轮任务为各轮合计，不是每轮40–80个。按独立计分条目统计，条目内不另计分的子条件不另算考点。用户或项目已有明确数量、分值与计分约定时优先遵守；仅做正文精简或核验，不自动改成40–80个。不为达到区间机械拆碎同一结果、重复计分或添加无关要求；数量不能代替具体性与覆盖完整性。

## 正文边界：细化结果，不写解题过程

**考点正文只保留已有编号、分值、具体正确结果或通过条件，以及必要的对象、窗口、单位与容差。** 不写解题思路、操作步骤、推导、复算过程、常见错误、错误示例、证据来源、文件页码或作者说明。这些内容需要时仅记在作者记录中，不拼接到交付的考点正文。

不能用增加“依据、思路、易错点”栏目来代替细化。细化应回答：什么结论、什么数量、什么状态或什么具体条件才得分？“给出后续24小时全部3班的具体接纳及运行交接数量”只要求有答案，没有说答案是什么，不能作为定稿考点。

- **固定结果：**先独立复核，再填实际数值、明确状态或可接受区间，带单位和必要容差。不能只写“数量正确”“与标答一致”“详见核验表”，也不能留待填数值冒充定稿。
- **真正开放的数量与方案：**写出带实际参数的容量、范围、时窗、业务目标和接受条件，不强制某一组唯一数量；不能用“满足公开限制”“整体可行”“取舍合理”代替具体约束。
- **原因、版本与状态判断：**写应识别的具体原因、适用范围或状态结论，以及允许保留的不确定范围。不要写模型该先查什么、怎样推导；不能只剩“解释充分”“证据相容”。

关键数值多时可用结果序列、分组范围和紧凑表述压缩，不能删掉独立的核心结果。作者尚未读取完整输入或未核出数值时，先留作者侧待核，不编造本题数字，也不输出空泛的“最终考点”。不写证据来源不等于删除所考的专业事实与结论。

## 八项写法

| 原则 | 落地写法 | 重点排查 |
|---|---|---|
| 1. 原子化 | 一条对应一项可独立判断的结果；计算值与原因分析若可分别对错，就拆开 | “算对且分析全面且方案合理”混成一条；反过来把一次错误机械拆成多条扣分 |
| 2. 答案依据准确 | 作者侧核对输入、规则与复算；正文落到已复核的结果或具体接受条件 | 将来源、推导复制进正文；作者偏好冒充唯一事实 |
| 3. 客观可判 | 正文写可判定的结果与条件；核查位置、取证和判卷记录留作者侧 | “全面、深入、有洞察力”；仅出现关键词或自称完成就通过 |
| 4. 具体 | 写明具体结论、实际数值或带实际参数的约束，保留必要对象、时点与口径 | 只写“给出数量”“完整交清”“满足限制”，没有对应结果 |
| 5. 接受合理等价 | 接受同义表达、有效算法与满足目标的替代方案；近似范围预先界定 | 把词语、固定排序或作者算法当唯一答案；以“近似”为由放过实质错误 |
| 6. 用例校准 | 作者侧用正确、错误及边界答案校验；正文不附常见错误或测试用例 | 将错误示例写进考点；未检验替代解就暗设唯一清单 |
| 7. 去重 | 比较各条查的能力、结果与错误原因；保留独立需求，合并重复表述 | 预算存在、预算表存在、预算明细存在反复计分；同一根因在多个格式里重复扣分 |
| 8. 单位与容差 | 数值写单位、口径、参考值或区间、比较符、容差及舍入方式；标识和离散状态可要求精确匹配 | “正确即可”；百分比与百分点混淆；“误差5%”未说明相对还是绝对 |

“客观可判”不限制是否使用“是否”等词。需要完整覆盖一组不可分的要求时，可定义一个完整性条件；该条件与各分项不能再重复计分。现有整体 0/1 条目包含多项条件时，作者侧逐条件核验再汇总，不擅自增加考点数量或改变分值；独立条目是否拆分按本次授权与计分约定处理。

当前使用 0/1 判分时，合理近似、同义表达和替代方案仍可通过预先定义的条件，二元判分不要求逐字匹配。采用其他评分方式时保留当前约定，不由技能另设权重或分值。

接受近义术语前核对分子、分母、期间、对象范围与单位。词语相近不代表口径相同；例如按订单数计算与按人数计算的“人均消费”不能只凭名称互换。

数值复算或表达容差不自动放宽业务硬约束、质量资格及资源边界；测量不确定性是否影响放行，应由输入中的业务规则确定。不能因参考计算允许小幅差异，就给超限方案额外余量。

## 考点记录与改写

在 [作者记录](../assets/design-record.md) 中为每条填写：要求依据、应查产物与位置、通过条件、容差/替代解、失败例，以及和其他考点的关系。尚未读取或形成完整的本次模型输入、无法独立复算时，考点只能是待核验草案。允许编写、扩充材料并主动设计错误；参考值须能由本次输入和适用规则复核，不能把未提供给模型的私下设定当成判分依据。

下面只演示短考点句式，假定数字及边界已由作者复核；不代表用户第六题的实际答案，不能直接移植。正式应用须填本题已核实的值，不把右列再改回“填写参考值”之类的写作指令。

| 薄弱考点 | 具体考点句式示意 |
|---|---|
| 给出后续24小时全部3班的具体接纳数量 | 3班接纳量依次为32、28、20 m³，各班绝对误差不超过0.1 m³。 |
| 正式检验代表量与待复核量相容 | 本项目正式代表量48 m³、待复核量12 m³，两项绝对误差均不超过0.1 m³。 |
| 选择有效版本并说明理由 | A批次适用V2.1，B批次维持待复核状态。 |
| 开放方案满足全部容量限制 | 3班接纳量分别在10–20、15–25、5–15 m³内，总量在45–50 m³内，均含端点；接受满足上述条件的不同分配。 |

数值条件要能实际执行。例如作者已独立复核某结果为 150%，允许绝对偏差 5 个百分点，则通过区间是 145%–155%，包含端点；若允许相对误差 5%，区间是 142.5%–157.5%。两者不同，不能只写“±5%”。这些数值只解释容差，不替实际题目确定标准答案。

建议、风险与原因类考点要接受材料支持的其他有效表述；同义重复不能当多项，不相关常识也不能凑数。实际必要风险必须在要求或材料中有依据；“至少几类”应由业务覆盖需求决定，不是通用难度配额。

总额与构成金额可以对应不同结果，但应说明为什么需要独立评价。若总额仅机械相加，且同一误录会让总额和所有派生项一起错，检查是否重复测量了一个失败；不要按列数拆出大量考点。

## 隐性专业判断与公平边界

隐去的是解题导航，不能藏起判定依据。可以让模型自行发现当前瓶颈、识别专业惯例、选择适用规则，但要核验：

- 目标、对象和必要背景足以让具备该岗位能力的人知道要解决什么。
- 非通用参数、特定制度、合同例外、生效范围或争议口径，在模型输入或允许使用的可访问来源中有依据。
- 行业惯例确实适用于当前任务；存在地区、版本或口径差异时提供能裁定的依据。只存在作者脑中的规则不能作为失败条件。
- 开放决策按目标、约束、证据和可执行结果判分，不要求选中作者偏爱的方案或立场。

不要在 prompt 中指出哪份材料错、哪条规则优先或考点位置。可将必要的业务条件补进自然资料，由模型判断；不用作者裁定表替它作判断。

## 区分度：检查题目真正难的部分是否被测到

用 [H1–H6 能力层次](task-portfolio.md) 标记考点，核对证据裁定、可恢复错误、约束求解、变更传播与业务取舍是否有结果检查。格式、关键词和模板齐全等低区分度点，不应淹没这些专业结果。

保持业务必需的验收条件，删除无意义或重复的格式奖励；没有依据时不随意删掉模型已做对的项目。若大部分得分来自常规整理，优先给 prompt 和附件增加真正影响结果的判断，再让考点覆盖它。源文的送分占比建议不作为跨项目固定比例。

反向检查：若模型犯了预期的实质错误，哪条考点会失败？如果没有，修复遗漏；若一处错误造成大量重复失败，合并或说明独立的结果要求。还要拿合理替代解、合法异常和边界值检查，会不会被误判。

## 同根错误的最小修正复核

在冻结评分规则时明确同根处理口径。疑似一个错误机械传播到多个结果时，按既有规则在作者侧核对；不因看到分数才临时改变权重、分母或去重政策。已有计分合同另有约定时，先说明差异，不暗改评分。

1. **定位根因与依赖。** 写清已证实的上游错误、受影响对象和派生结果。相似措辞、同一公式名或同属一类知识，不足以证明同根；不同现场中的独立缺项也不能一概合并。
2. **只做最小修正。** 保持作答者原有方法、控制、分配和决定不变，只替换已证实错误的上游值或状态，重算其确定性下游结果。所需关系须来自实际作答或可唯一恢复的底稿，不能调用作者求解器重新排程、另选参数或补写缺失工作。
3. **检查是否还有独立失败。** 最小修正后，下游原有计算和条件均成立，才支持按同根规则归并；若仍有规格、资格、时间、资源等独立违反项，保留相应失败。无法唯一复算时记录证据不足，不凭猜测归并。
4. **分开报告评分与合法性。** 留存原始判定、归并关系、调整及最终分数。归并避免重复计罚，不表示原方案已可执行，也不代表作者修正过的结果就是模型实际完成的结果。

此记录不进入考点正文；正文仍只写具体业务结果和接受条件。同根处理不会使同一错误在多个格式出现时变成多个独立考点。

## 评分前核验

以下核验及记录均留作者侧，不附到考点正文：

1. **先核答案再写短考点。** 将参考产物逐条独立复算，区分固定结果和真正开放结果；定稿正文必须有实际数值、状态或具体条件。依据、来源、步骤和常见错误不进入正文。
2. **查实际结果。** 为每个条件记录实际产物位置、观察结果、比较结果与满足状态。答案自称“全部闭合”“符合限制”不能代替核对。确实漏交与判卷读取失败分开处理；读取失败记待核，不能假装已通过。
3. **按既有计分汇总。** 整体 0/1 时逐条件确认，再按已确定的计分规则汇总；不因解释完整、表格齐全而跳过数值与约束，不临时修改分值。
4. **用有实质差异的答案校准。** 对已核验的答案副本，只将一项结果改成超出既定容差、违反公开约束的数值或错误状态，保留完整措辞，检查对应判定能否识别失败；再检查正确解、合法替代解及边界值能否通过。只换说法或改成另一合法分配不算错误样本。错误仍通过或正确替代解被拒绝时，修判定条件或判卷执行，不把样本及解释写入考点。
5. **冻结版本。** 冻结 prompt、输入、标答、考点及评分分母，再进行 [独立试测](rounds-and-validation.md)。因遗漏修订考点时保留新旧版本，不把同一旧回答的重评分称作新版题目的独立试测。

改考点只能提高测量准确度。是否增加题目难度和必要轮次，还要看模型在修订 prompt 与附件后的实际判断、产物和执行记录。
