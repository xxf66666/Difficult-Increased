# PDF：TeX 制作、浅水印与可读性

这是用户的制作偏好，作用于作者新建或重排的 PDF，不是三份来源文档中的项目规定，也不要求作答模型必须安装 TeX。

## 制作约定

1. 用 TeX / LaTeX 生成新增或重排的 PDF，保存 `.tex`、外部资源、编译命令/编译器信息与成功日志。中文通常选择 XeLaTeX 或 LuaLaTeX，字体按实际环境选择，不假定某台电脑的字体存在。
2. 有内置 TeX 编辑器与编译器时优先使用；其他 Agent 在可用环境编译。模板或源码已经写出不等于 PDF 已成功生成。缺编译器时报告实际情况，不把未验证的源文件称作成品。
3. 保留原始 PDF 与其哈希。若需重排，输出独立副本并记录哪些内容或版式改变；不要伪造原件扫描、签章、手写历史或正式签发状态。
4. 版式服务于资料本身：标题层级、页码、表头重复、长表分页、脚注与图表引用一致；数字、单位和注释不截断。新建附件不应统一成每份一页、每页一个答案的过度整洁模板。

## 噪声的两层

**业务信息噪声是主体。** 保留有来源的相关背景、历史记录、非关键段落、旧状态、正常空值和分散的有效线索。需要模型筛选、拼接和判断，才对难度与工作量有作用。

**视觉噪声只作轻微呈现。** 新建或重排的材料可用浅水印、边缘细纹等。不能把关键内容变浅、模糊或旋转到无法稳定识读，不能盖住数字、单位、签发日期或脚注。

浅水印可从很低的不透明度试起，例如 0.03–0.06，再按实际页面渲染结果调整；这只是排版起点，不是固定噪声指标。水印用真实用途文字，不伪造“已批准”“已签署”等业务状态。边缘噪声如有，应与正文保持空间分离，采用可复现的设置，不制造每次编译不同的输入。

TeX 中的一个实现片段（需要按实际文档类、字体、页面布局适配）：

```tex
% 放在已可成功编译的 TeX 文档导言区；不是完整文档。
\usepackage{tikz}
\usepackage{eso-pic}
\AddToShipoutPictureBG{%
  \begin{tikzpicture}[remember picture,overlay]
    \node[rotate=30,text=gray,opacity=0.035,scale=5]
      at (current page.center) {资料副本};
  \end{tikzpicture}%
}
```

不要把整份 PDF 栅格化或破坏文本层来增加难度。原件本身是扫描件时保留原件属性，并验证任务环境具备必要识读能力；关键证据若读不出，要修复可作答性。

## 交付验收

- 确认编译成功，检查缺字、缺图、截断、长表错位、页码和引用。
- 渲染页面检查整体布局，逐项放大检查承担结论的数字、单位、版本、生效时间、附注和小表格。
- 检查文本提取与表格读取；有文本层也要核对视觉内容，两者不能互相矛盾。不要只凭文件非空通过。
- 与原始材料核对正文与表格事实，保留跨附件的对象、时间、数量和规则关系。
- 确认水印没有透露正确答案、考点位置、难点机制或错误地表示审批状态。

记录最终 PDF、源文件、编译状态、渲染检查和内容核对结果。PDF 更漂亮或更有原始材料感，均不能单独证明题目难度提高。
